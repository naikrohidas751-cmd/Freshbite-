# Freshbite

Freshbite is a food ordering website with a JDK backend and an orders dashboard.

## Live site

- [Open the Freshbite storefront](https://freshbite-3.onrender.com/)
- [Open the customer orders dashboard](https://freshbite-3.onrender.com/admin) (requires the admin credentials configured in Render)

The storefront sends order and menu requests to the backend on the same site using `/api`.

## Run locally

Start the JDK backend from `backend-java` with `run.bat`, then open `http://127.0.0.1:5000/shop`. The local admin dashboard is at `http://127.0.0.1:5000/admin`.
